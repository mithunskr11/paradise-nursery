
# Paradise Nursery - Online Plant Shopping Application

## Project Description
Paradise Nursery is an online plant shopping application developed using React. It allows users to explore different categories of indoor plants, add plants to their shopping cart, and manage their selected items.

## Features
- Attractive landing page with a nursery background image.
- About Us section describing Paradise Nursery.
- Three categories of indoor plants.
- Six or more unique plants in each category.
- Plant images, names, and prices.
- Add to Cart functionality.
- Cart item count displayed in the navigation bar.
- Increase or decrease plant quantities.
- Remove items from the shopping cart.
- Automatic calculation of total prices.
- Checkout message displaying "Coming Soon".
- Continue Shopping option.

## Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3
- Redux Toolkit
- React Redux
- React Router DOM
- Vite

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/mithunskr11/paradise-nursery.git
   ```

2. Navigate to the project folder:

   ```bash
   cd paradise-nursery
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.
